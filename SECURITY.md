# Security Policy

## Supported versions

Only the latest commit on `master` gets security fixes.

## Reporting a vulnerability

Please do not open a public issue.

Report it privately through GitHub: go to the **Security** tab of this repository and click **Report a vulnerability**. If you cannot use GitHub, email jakub@wojak.works instead. Include:

- what the problem is and where it is (file, route, endpoint),
- steps to reproduce or a proof of concept,
- the impact you expect.

You should get a reply within 7 days. Once the issue is confirmed, a fix is prepared and released, and you are credited in the advisory unless you ask otherwise.
